# AI Vineyard Productivity

Welcome to the AI Vineyard Productivity repository!

This repository contains tools and applications for agricultural data analysis, including the **Agrixel Image Download & Explorer** — a Streamlit web application that configures satellite imagery downloads (such as Sentinel-1 and Sentinel-2) and provides an interactive map and time-series explorer for the data.
